# Fontes do relatório PDF

Inter (pesos 400, 500, 600 e 700, subconjunto latino) do projeto Inter (https://github.com/rsms/inter),
obtida pelo pacote `@fontsource/inter`. Licença SIL Open Font License 1.1 (ver `OFL-LICENSE.txt`),
que permite uso e incorporação em documentos. Usada por `src/lib/pdf/report-theme.ts`.
