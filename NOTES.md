## Como rodar
- `npm run dev` ou `npm run build && npm run start` (interface); `npm run worker:prod` (Worker de auditorias; obrigatório para auditar).
- Testes: `npm test`, `npm run typecheck`, `npm run build`. Sem ESLint instalado.
- Diagnóstico (sem custo e sem alterar dados): `npm run db:check`, `npm run validate:recovery`, `npm run rls:probe`, `npm run pdf:migrate -- inventory`, `GET /api/system/health`.
- Operação diária: `docs/phase5/operations-runbook.md`.

## Regras que não mudam
- Nunca modificar o `.env.local` automaticamente.
- Nenhuma consulta paga (Serper) sem autorização expressa; uma auditoria = 49 consultas.
- Nunca inventar dados; dado não comprovado = `NOT_VERIFIED`; simulação só com `GMN_DEMO_MODE=true`.
- Score Juiz histórico gravado nunca é recalculado; pontuações armazenada × recalculada × verificada ficam separadas.
- Nada histórico (PDFs, auditorias) é apagado, movido ou sobrescrito sem autorização.
- Sem DataForSEO, sem Google Business Profile API, sem novos serviços pagos.
